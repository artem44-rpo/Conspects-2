#### Создание и редактирование таблиц

В LibreOffice Calc таблицы состоят из строк и столбцов. На их пересечении находятся ячейки, в которые можно записывать текст, числа и другую информацию.

При работе с таблицей можно выполнять следующие действия:

- изменять содержимое ячеек;
- добавлять новые строки и столбцы;
- удалять ненужные строки и столбцы;
- настраивать ширину столбцов;
- изменять высоту строк.

Эти возможности позволяют удобно организовывать данные и редактировать таблицы.

#### Сортировка таблиц

Сортировка используется для расположения информации в определённом порядке.

В LibreOffice Calc для этого применяется команда «Данные» → «Сортировка».

Перед выполнением сортировки необходимо выделить нужный диапазон ячеек.

Данные можно сортировать:

- по возрастанию;
- по убыванию;
- в алфавитном порядке.

Например, числа можно расположить от меньшего к большему или наоборот, а текст — по алфавиту.

#### Вычисления в таблицах

В LibreOffice Calc расчёты выполняются с помощью формул.

Каждая формула начинается со знака `=`.

Примеры формул:

- `=A1+B1` — складывает значения двух ячеек.
- `=SUM(A1:A5)` — вычисляет сумму значений в указанном диапазоне.
- `=AVERAGE(A1:A5)` — определяет среднее арифметическое чисел.

Чтобы выполнить вычисление, нужно ввести формулу в ячейку и нажать Enter.

После этого программа автоматически рассчитает результат и отобразит его в выбранной ячейке.

#### Преобразование текста в таблицу

В LibreOffice можно преобразовать обычный текст в таблицу.

Для этого используется команда «Таблица» → «Преобразовать» → «Текст в таблицу».

Порядок действий:

1. Выделить текст, который необходимо преобразовать.
2. Открыть меню «Таблица».
3. Выбрать «Преобразовать» → «Текст в таблицу».
4. Указать разделитель, например табуляцию.
5. Подтвердить преобразование.

После выполнения этих действий текст будет распределён по строкам и столбцам.

#### Открытие приложения табличного процессора и структура экрана

Для создания электронных таблиц используется программа LibreOffice Calc.

После запуска открывается рабочее окно, в котором можно создавать новые таблицы и редактировать существующие.

Основные элементы окна:

- строка заголовка;
- главное меню;
- панели инструментов;
- строка формул;
- рабочая область;
- полосы прокрутки;
- строка состояния.

Рабочая область состоит из строк и столбцов.

Строки обозначаются числами, а столбцы — латинскими буквами.

Каждая ячейка имеет свой адрес, который определяется названием столбца и номером строки.

Например: A1, B2 или C5.

#### Меню и панели инструментов

Главное меню находится в верхней части окна LibreOffice Calc.

Через него можно выполнять основные операции с документами:

- создавать новые файлы;
- открывать готовые документы;
- сохранять изменения;
- редактировать таблицы;
- сортировать информацию;
- использовать дополнительные функции.

Панели инструментов содержат кнопки для быстрого доступа к наиболее часто используемым командам.

С их помощью можно:

- сохранять документы;
- изменять оформление текста;
- выравнивать данные в ячейках;
- добавлять границы таблиц;
- выполнять другие действия с документом.

Использование панелей инструментов помогает быстрее работать с таблицами.

#### Создание и сохранение документа

Для создания новой электронной таблицы необходимо открыть меню:

«Файл» → «Создать» → «Электронная таблица».

После этого появится новая книга Calc, в которую можно вводить данные.

Для сохранения документа используется команда «Файл» → «Сохранить как».

При сохранении нужно:

1. Указать название файла.
2. Выбрать папку для сохранения.
3. Определить нужный формат документа.
4. Подтвердить сохранение.

После этого файл будет сохранён в выбранном месте.

#### Знакомство с элементами окна

Окно LibreOffice Calc состоит из нескольких основных элементов, каждый из которых выполняет свою задачу.

**Строка заголовка** — находится в верхней части окна и показывает название открытого документа.

**Главное меню** — содержит команды для управления программой и работы с таблицами.

**Панели инструментов** — позволяют быстро выполнять основные операции без поиска нужных команд в меню.

**Рабочая область** — основная часть окна, в которой находятся таблицы и выполняется работа с данными.

**Строки** — горизонтальные части таблицы, которые обозначаются числами.

**Столбцы** — вертикальные части таблицы, обозначаемые буквами.

**Ячейки** — отдельные элементы таблицы, предназначенные для ввода текста, чисел и формул.

**Строка формул** — позволяет просматривать и изменять содержимое выбранной ячейки.

**Полосы прокрутки** — используются для перемещения по таблице в разных направлениях.

**Строка состояния** — находится в нижней части окна и отображает дополнительную информацию о документе.

Знание этих элементов помогает быстрее ориентироваться в LibreOffice Calc и удобнее работать с электронными таблицами.
