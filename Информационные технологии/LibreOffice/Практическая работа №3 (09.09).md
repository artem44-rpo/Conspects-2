#### Просмотр документа

В LibreOffice Writer есть несколько способов просмотра документа:

- Обычный — стандартный режим для работы с текстом.
- Веб — отображение документа в виде веб-страницы.
- Во весь экран — документ показывается на всём экране.

Также можно настроить масштаб. Он изменяет только размер отображения документа, не влияя на настоящий размер текста.

#### Перемещение по документу

Для перемещения по документу можно использовать мышь, полосу прокрутки или клавиатуру.

Клавиша F5 открывает Навигатор, через который удобно переходить к страницам, заголовкам, таблицам, закладкам и другим элементам.

Основные сочетания клавиш:

- Home — переход в начало строки.
- End — переход в конец строки.
- Page Up — прокрутка на экран вверх.
- Page Down — прокрутка на экран вниз.
- Ctrl + Home — переход в начало документа.
- Ctrl + End — переход в конец документа.

Чтобы открыть конкретную страницу, используется команда «Перейти».

#### Закладки

Закладка — это специальная отметка в документе, позволяющая быстро вернуться к нужному месту.

Для создания закладки необходимо:

1. Установить курсор в нужном месте.
2. Открыть меню «Вставка» → «Закладка».
3. Указать название закладки.
4. Нажать «Добавить».

После создания закладку можно найти в общем списке и перейти к отмеченному месту.

#### Гиперссылки

Гиперссылка позволяет быстро переходить к другим ресурсам или частям документа.

Она может вести:

- на интернет-сайт;
- к другому файлу;
- на адрес электронной почты;
- к определённому месту документа.

Чтобы добавить гиперссылку:

1. Выделить нужный текст.
2. Открыть «Вставка» → «Ссылка».
3. Указать адрес или место перехода.
4. Подтвердить создание ссылки.

#### Оформление текста

В текстовом редакторе можно настраивать внешний вид документа.

Основные параметры:

- тип шрифта;
- размер букв;
- начертание текста;
- выравнивание;
- отступы;
- межстрочные интервалы;
- расстояние между абзацами.

Для удобного оформления используются готовые стили.

Основные стили:

- Обычный — для основного текста документа.
- Заголовок 1 — для главных разделов.
- Заголовок 2 — для подразделов.
- Заголовок 3 — для более мелких разделов.

#### Титульный лист

Титульный лист — первая страница документа, на которой указывается основная информация о работе.

Создать его можно через меню «Вставка» → «Титульная страница».

Обычно титульный лист содержит:

- название учебного заведения или организации;
- тему работы;
- вид работы;
- ФИО студента или сотрудника;
- номер группы;
- ФИО преподавателя или руководителя;
- город;
- год выполнения работы.

#### Список литературы

Список литературы — перечень материалов, которые использовались при подготовке документа.

В него могут входить:

- книги;
- учебные пособия;
- статьи;
- интернет-сайты;
- электронные документы.

При оформлении источника указывают автора, название и другие необходимые сведения.

Список литературы обычно размещается в конце работы.

#### Страницы

Настройки страницы находятся в меню «Формат» → «Стиль страницы».

Здесь можно изменить:

- размер бумаги;
- ориентацию страницы;
- поля;
- колонтитулы;
- фон страницы.

Основные виды ориентации:

- Книжная — вертикальное расположение листа.
- Альбомная — горизонтальное расположение листа.

#### Разрыв страницы

Разрыв страницы используется для переноса текста или нового раздела на следующую страницу.

Добавляется через меню «Вставка» → «Разрыв страницы».

Такой способ удобнее, чем многократное нажатие Enter, потому что позволяет сохранить правильное оформление документа.

#### Разделы документа

Раздел — отдельная часть документа, для которой можно задать собственные настройки.

Например, в разных разделах можно использовать:

- различную ориентацию страниц;
- разные размеры полей;
- отдельные колонтитулы;
- собственную нумерацию страниц;
- разное количество колонок.

#### Нумерация страниц

Нумерация страниц позволяет автоматически добавлять номера к страницам документа.

Для её создания используется меню «Вставка» → «Номер страницы».

Номера могут располагаться:

- в верхней части страницы;
- в нижней части страницы;
- на полях.

Если количество страниц меняется, нумерация автоматически обновляется.

#### Колончатый текст

Колонки позволяют разделять текст на несколько вертикальных частей.

Для их создания используется меню «Макет» → «Колонки».

Можно выбрать:

- одну колонку;
- две колонки;
- три колонки;
- собственные настройки.

Дополнительно можно регулировать ширину колонок и промежутки между ними.

#### Внесение исправлений

Во время редактирования документа можно выполнять различные действия с текстом:

- добавлять новые фрагменты;
- удалять ненужный текст;
- заменять отдельные слова;
- копировать информацию;
- перемещать текст;
- находить нужные слова;
- выполнять поиск и замену.

Функция отслеживания изменений помогает увидеть, какие исправления были внесены.

Она показывает:

- добавленные фрагменты;
- удалённый текст;
- изменения оформления.

Каждое исправление можно принять или отклонить.

#### Примечания

Примечание — это комментарий, который добавляется к определённому участку документа.

С помощью примечаний можно оставлять замечания, объяснения или дополнительную информацию, не изменяя основной текст.

#### Составные документы

Составной документ включает несколько видов содержимого.

Например:

- обычный текст;
- таблицы;
- изображения;
- диаграммы;
- гиперссылки;
- другие объекты.

Все эти элементы могут находиться в одном документе.

#### Слияние документов

Слияние документов позволяет создавать несколько документов по единому шаблону.

Например, с помощью этой функции можно подготовить письма для разных получателей, автоматически подставляя их имена и адреса.

Для слияния необходимы:

- Основной документ — общий текст, который используется как шаблон.
- Источник данных — информация, подставляемая в документ, например имена и адреса.

#### Колонтитулы

Колонтитул — область в верхней или нижней части страницы, содержащая дополнительную информацию.

В колонтитуле можно разместить:

- номер страницы;
- название документа;
- название раздела;
- дату;
- имя автора.

Для добавления используются команды:

- «Вставка» → «Колонтитулы» → «Верхний колонтитул».
- «Вставка» → «Колонтитулы» → «Нижний колонтитул».

Колонтитулы могут автоматически повторяться на нескольких страницах документа.

#### Сноски

Сноска — дополнительное пояснение к определённому фрагменту текста.

Обычно в тексте она обозначается небольшим номером, а само пояснение размещается в нижней части страницы.

Для добавления сноски используется команда «Ссылки» → «Вставить сноску».

#### Оглавление

Оглавление — список разделов документа с указанием страниц, на которых они находятся.

Для его создания используется меню:

«Вставка» → «Оглавление и указатели» → «Оглавление, указатель или библиография».

Чтобы оглавление создавалось автоматически, необходимо использовать стили заголовков:

- Заголовок 1.
- Заголовок 2.
- Заголовок 3.
