### Перемещение указателя ячейки

Активная ячейка — это ячейка таблицы, которая выбрана в данный момент и с которой выполняются действия.

В LibreOffice Calc перемещаться между ячейками можно с помощью мыши или клавиатуры.

Основные способы перемещения:

- Щелчок мышью по ячейке — делает её активной.
- Стрелки на клавиатуре — перемещают выделение на одну ячейку в нужную сторону.
- Enter — переход к ячейке на следующей строке.
- Tab — переход на одну ячейку вправо.
- Ctrl + стрелка — перемещение к границе заполненного диапазона.
- Home — переход к началу строки.
- Ctrl + Home — переход к первой ячейке A1.
- Ctrl + End — переход к последней используемой ячейке листа.

Эти команды позволяют быстрее перемещаться по большим таблицам.

### Выделение диапазонов

Диапазон — это одна или несколько ячеек таблицы, которые выбираются для выполнения определённых действий.

В LibreOffice Calc можно выделять отдельные ячейки, строки, столбцы и целые области.

Основные способы выделения:

- Одна ячейка — нажать на неё левой кнопкой мыши.
- Смежный диапазон — зажать левую кнопку мыши и провести указателем по нужным ячейкам.
- Shift + стрелки — расширить выделенную область в выбранном направлении.
- Столбец — нажать на букву его названия.
- Строка — нажать на номер строки.
- Весь лист — нажать кнопку в левом верхнем углу таблицы, между заголовками строк и столбцов.
- Несмежные диапазоны — выделить первую область, затем удерживать Ctrl и выбирать остальные.

Выделение диапазонов используется при копировании, форматировании и обработке данных.

### Ввод и редактирование данных

В ячейки LibreOffice Calc можно вводить различную информацию:

- текст;
- числа;
- даты;
- математические формулы.

Для ввода данных необходимо выбрать нужную ячейку и начать печатать с клавиатуры.

Основные команды:

- Enter — завершает ввод данных.
- Esc — отменяет ввод.
- F2 — позволяет изменить содержимое выбранной ячейки.
- Двойной щелчок мышью — открывает ячейку для редактирования.
- Delete — удаляет содержимое выделенных ячеек.

Также изменять уже введённую информацию можно через строку ввода, которая находится над рабочей областью таблицы.

### Установка ширины столбцов

В LibreOffice Calc можно изменять ширину столбцов, чтобы информация отображалась полностью и таблица выглядела аккуратно.

Основные способы настройки:

- Перетащить мышью границу между заголовками столбцов.
- Дважды нажать на границу столбца для автоматического подбора ширины по содержимому.
- Выделить нужный столбец и открыть «Формат» → «Столбцы» → «Ширина».
- Выделить несколько столбцов и задать для них одинаковую ширину.

Автоматический подбор особенно удобен, когда в таблице находятся длинные слова или большие числа.

### Автозаполнение

Автозаполнение — функция, которая позволяет быстро копировать данные или продолжать определённую последовательность.

Чтобы воспользоваться автозаполнением, необходимо:

1. Ввести начальное значение в ячейку.
2. Найти небольшой квадрат в правом нижнем углу выделенной ячейки — маркер заполнения.
3. Навести на него указатель мыши.
4. Зажать левую кнопку и протянуть маркер в нужном направлении.

Примеры использования:

- Если ввести числа 1 и 2, выделить их и протянуть маркер, последовательность продолжится: 3, 4, 5 и так далее.
- Если ввести «Понедельник», можно автоматически получить следующие дни недели.
- Если протянуть ячейку с формулой, она скопируется в соседние ячейки с автоматическим изменением относительных ссылок.

Автозаполнение помогает быстрее работать с большими объёмами данных.

### Формулы для смежного диапазона

Формула в LibreOffice Calc используется для выполнения вычислений и всегда начинается со знака `=`.

Примеры формул:

- `=A1+B1` — сложение значений двух ячеек.
- `=A1*B1` — умножение значений.
- `=SUM(A1:A5)` — вычисление суммы чисел из диапазона A1:A5.

Чтобы применить формулу к нескольким соседним ячейкам, необходимо:

1. Ввести формулу в первую ячейку.
2. Нажать Enter.
3. Выделить ячейку с готовой формулой.
4. Протянуть маркер заполнения на остальные ячейки.

Например, если в C1 находится формула `=A1+B1`, то при копировании на строку ниже, в C2, она автоматически изменится на `=A2+B2`.

Это происходит благодаря относительным ссылкам на ячейки.

### Формулы для несмежного диапазона

Несмежный диапазон — это несколько отдельных ячеек или областей таблицы, которые не расположены рядом друг с другом.

Например, можно выделить ячейки A1, C1 и E1, удерживая клавишу Ctrl.

Для вычислений с такими ячейками можно использовать формулы, в которых указываются отдельные адреса.

Пример:

- `=SUM(A1;C1;E1)` — складывает значения ячеек A1, C1 и E1.

Таким образом, функция SUM позволяет работать не только с последовательными диапазонами, но и с отдельными ячейками таблицы.

### Копирование формул

В LibreOffice Calc формулы можно переносить из одной ячейки в другую несколькими способами.

Основные команды:

- Ctrl + C — копирование формулы.
- Ctrl + V — вставка скопированной формулы.
- Маркер заполнения — быстрое копирование формулы в соседние ячейки.

При копировании формул относительные ссылки автоматически меняются в зависимости от нового расположения.

Например:

Если в ячейке B1 записана формула `=A1*2`, то после копирования в B2 она изменится на `=A2*2`.

Если необходимо сохранить адрес ячейки неизменным, применяется абсолютная ссылка со знаком `$`.

Пример абсолютной ссылки:

`=$A$12`

При копировании формулы такой адрес останется прежним.

### Копирование формул в несмежные ячейки

Формулы можно копировать не только в соседние, но и в отдельные ячейки, расположенные в разных частях таблицы.

Порядок действий:

1. Ввести формулу в исходную ячейку.
2. Выделить её и нажать Ctrl + C.
3. Удерживая Ctrl, выбрать необходимые несмежные ячейки.
4. Нажать Ctrl + V для вставки.

При копировании программа учитывает типы ссылок, которые используются в формуле.

Относительные ссылки изменяются в зависимости от положения новой ячейки, а абсолютные остаются неизменными.

Это позволяет использовать одну формулу для выполнения одинаковых вычислений в разных частях таблицы.
