#### Работа с рисунками в документе

В LibreOffice Writer можно вставлять в документ различные изображения: рисунки, фотографии, схемы и другие графические объекты.

Для добавления изображения используется меню «Вставка» → «Изображение». Также можно воспользоваться сочетанием клавиш Ctrl + V, если картинка заранее скопирована.

После вставки изображение можно перемещать, изменять его размер и поворачивать.

#### Вставка рисунков

После добавления изображения становятся доступны инструменты для его редактирования.

Можно изменять:

- ширину и высоту изображения;
- расположение на странице;
- границы рисунка;
- другие параметры оформления.

Размер картинки удобно менять с помощью маркеров по углам. Это помогает сохранить правильные пропорции изображения.

Для точной настройки размеров можно открыть свойства рисунка.

#### Составление блок-схемы

Блок-схема — графическое представление алгоритма, состоящее из различных фигур и соединительных линий.

В LibreOffice блок-схемы создаются с помощью инструментов рисования.

Основные элементы блок-схемы:

- Прямоугольник — обозначает действие или операцию.
- Параллелограмм — используется для ввода или вывода данных.
- Ромб — обозначает проверку условия.
- Овал — показывает начало или завершение алгоритма.
- Стрелки и линии — указывают порядок выполнения действий.

#### Переупорядочивание слоёв рисунка и вращение фигур

Если несколько изображений или фигур находятся в одном месте и перекрывают друг друга, можно изменять порядок их расположения.

Для этого используются команды:

- На передний план.
- На задний план.
- На один уровень вперёд.
- На один уровень назад.

Эти команды позволяют определить, какой объект будет находиться поверх остальных.

Также фигуры можно поворачивать. Для этого нужно выделить объект и воспользоваться инструментом поворота или специальными маркерами.

Настройка слоёв особенно полезна при создании схем и сложных изображений.

#### Создание рисунка-подложки для текста

Рисунок-подложка — изображение, которое располагается на фоне текста.

Чтобы сделать подложку, необходимо вставить картинку, переместить её за текст и настроить положение на странице.

Такой способ используется для:

- оформления документов;
- создания фоновых изображений;
- добавления водяных знаков;
- размещения текста поверх рисунка.

#### Управление обтеканием рисунка текстом

Обтекание определяет, каким образом текст будет располагаться рядом с изображением.

Эту настройку можно изменить в свойствах рисунка.

Основные варианты:

1. Без обтекания — текст располагается отдельно от изображения.
2. Обтекание — текст размещается вокруг рисунка.
3. Сквозное — текст может находиться рядом с рисунком или поверх него.
4. На задний план — изображение располагается за текстом.
5. На передний план — изображение перекрывает текст.

Правильное обтекание помогает аккуратно расположить изображения внутри документа.

#### Работа с научными формулами

В LibreOffice Writer есть специальный редактор LibreOffice Math, предназначенный для создания математических и научных формул.

С его помощью можно добавлять:

- дроби;
- степени;
- квадратные корни;
- индексы;
- интегралы;
- суммы;
- другие математические обозначения.

Для вставки формулы используется меню «Вставка» → «Объект» → «Формула».

После этого открывается редактор, в котором формула вводится с помощью специальных команд.

Уже добавленные формулы можно изменять и редактировать.

Примеры команд:

- Дробь — `a over b`
- Степень — `x^2`
- Нижний индекс — `a_1`
- Квадратный корень — `sqrt{x}`
- Сумма — `sum from {i=1} to {n} i`
- Интеграл — `int x dx`
- Формула корней квадратного уравнения — `x = {-b +- sqrt{b^2 - 4ac}} over {2a}`

#### Табличный процессор

LibreOffice Calc — программа для создания и обработки электронных таблиц.

Она позволяет:

- хранить информацию в таблицах;
- выполнять вычисления;
- использовать формулы и функции;
- создавать диаграммы;
- обрабатывать большие объёмы данных.

Документ Calc состоит из одного или нескольких листов.

Каждый лист содержит строки и столбцы. Места их пересечения называются ячейками.

У каждой ячейки есть собственный адрес, например A1, B2 или D5.

В ячейки можно записывать текст, числа, даты и формулы.

#### Создание книг

В LibreOffice Calc основной документ называется электронной книгой.

Одна книга может включать несколько листов, предназначенных для разных задач.

Листы можно:

- создавать;
- удалять;
- переименовывать;
- перемещать;
- менять местами.

Например, в одной книге можно разместить отдельные листы со списком сотрудников, товарами и финансовыми расчётами.

Для создания новой книги используется команда:

«Файл» → «Создать» → «Электронная таблица».

#### Форматирование таблиц

Форматирование в Calc позволяет изменять оформление таблицы, чтобы информация была более понятной и удобной для чтения.

При этом внешний вид ячейки может измениться, а её значение останется прежним.

Основные параметры форматирования:

- тип и размер шрифта;
- выравнивание текста;
- цвет текста и фона;
- границы ячеек;
- ширина столбцов;
- высота строк;
- отображение чисел, дат, процентов и денежных значений.

#### Специальные возможности Calc

LibreOffice Calc предоставляет дополнительные инструменты для работы с таблицами.

К ним относятся сортировка, фильтрация, условное форматирование, диаграммы и автоматические вычисления.

**Сортировка** — расположение данных в определённом порядке. Например, по алфавиту или по возрастанию чисел.

**Фильтрация** — отображение только тех строк, которые соответствуют выбранным условиям.

**Условное форматирование** — автоматическое изменение внешнего вида ячеек в зависимости от их содержимого.

Например, можно настроить выделение оценок ниже определённого значения.

Также Calc поддерживает управление с клавиатуры, что позволяет выполнять многие действия без использования мыши.

#### Формулы

Формулы в LibreOffice Calc нужны для автоматического выполнения вычислений.

Любая формула начинается со знака `=`.

В формулах можно использовать:

- числа;
- адреса ячеек;
- арифметические операции;
- встроенные функции.

Основные арифметические операторы:

- Сложение — `+`
- Вычитание — `-`
- Умножение — `*`
- Деление — `/`
- Возведение в степень — `^`

Основные функции Calc:

- **СУММ()** — складывает числа из выбранного диапазона.
  Пример: `=СУММ(A1:A10)`

- **СРЗНАЧ()** — рассчитывает среднее арифметическое.
  Пример: `=СРЗНАЧ(B1:B10)`

- **ЕСЛИ()** — проверяет условие и возвращает результат в зависимости от его выполнения.
  Пример: `=ЕСЛИ(A1>10;"Много";"Мало")`

- **МАКС()** — определяет максимальное значение.
  Пример: `=МАКС(A1:A10)`

- **МИН()** — находит минимальное значение.
  Пример: `=МИН(A1:A10)`

- **СЧЁТ()** — подсчитывает количество ячеек с числовыми значениями.
  Пример: `=СЧЁТ(A1:A10)`

Использование формул помогает ускорить расчёты и уменьшить количество ошибок при работе с данными.

#### Макросы

Макрос — последовательность команд, которая выполняется автоматически.

В LibreOffice макросы используются для автоматизации повторяющихся действий.

Для их создания чаще всего применяется язык программирования LibreOffice Basic.

С помощью макросов можно:

- автоматически заполнять таблицы;
- изменять оформление ячеек;
- обрабатывать информацию;
- выполнять несколько действий одной командой;
- автоматизировать работу с документами.

Макросы находятся в меню «Сервис» → «Макросы».

Формулы и макросы выполняют разные задачи.

**Формулы** используются для вычислений непосредственно в ячейках таблицы.

**Макросы** позволяют автоматизировать различные операции и управлять документом с помощью программного кода.
