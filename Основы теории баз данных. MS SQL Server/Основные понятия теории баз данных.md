**Данные** - это информация представлена в определенном виде, может быть хаотичным или упорядоченном формате.

**База данных** - совокупность данных, организованных по определенным правилам, предусматривающая хранение, описание, манипулирование и удаление данных.

**СУБД** (система управления базы данных) - Это целый комплекс программ, позволяющие создавать базу данных и манипулировать данными

Язык запросов - SQL. Это специализированный язык, предназначенный для работы БД.

Особенности SQL:
-  не является самостоятельным ЯП
-  имеет четкую структуру, близок к естественному English language
-  имеет декоративный характер
-  при написании кода, пользователь указывает что хочет получить, а система сама определяет как выполнить задачу
-  в нём нет циклов, ветвей и других привычных процедурных конструкций

#### Список диалектов SQL
-  T-SQL (TransactSQL) именно он используется в MS SQL Server
-  PL/SQL (Procedural Language/SQL) используется в Oracle
-  SQL/PSM используется в MySQL
-  PLpg/SQL - используется в PostgreSQL
-  Jet SQL - используется в Microsoft Access

### Модели баз данных
Это способ структурирования данных и описание взаимосвязей между ними

##### Файловая модель
Состоит из поля, файла и записи. Нет связей между файлами

##### Иерархическая модель
Появились связи - родитель и потомок

У связи родитель-потомок - только 1 родитель

##### Сетевая модель
Представляет собой развитие иерархической модели. Модель позволяет описывать более сложные связи. Появляется связь много ко многому

##### Реляционная модель
Данные представляются в виде таблиц. В этой модели присутствуют связи 1:1, 1:многому, и много:многому

##### Гибридная модель (объектно-реляционная)
Тяжело поддерживать


### Основные понятия реляционной модели
- **Сущность** (таблица) - это представление набора реальных или абстрактных объектов (люди, аудитории, события, места) которые имеют общие характеристики
- **Атрибут** (подзаголовок столбца) - именование характеристик являются частью сущности 
- **Кортеж** (одна строка) - это каждая строка сущности в которой хранятся данные разных типов
- Связь - это некая взаимосвязь между двумя сущностями

##### Виды связей
-  1:1 (1-1) - одна запись из главной таблицы соответствует только 1 записи из 2 таблицы (у класса только один преподаватель и у преподавателя один класс)
-  1-N - самая часто используемая связь. Одна запись из главной таблицы к нескольким записям второй таблицы (куриная лапка(в конце запись раздваивается на несколько))
-  N-N (двойная куриная лапка). Самая сложная связь
-  0,1 или N записей в главной таблице может соответствовать 0,1 или N записям из другой таблицы
**Первичный ключ** (уникальный) - это уникальное поле, которое идентифицирует каждый кортеж сущности
**Вторичный ключ** (внешний) - столбец или набор столбцов в одной таблице которая ссылается на первичный ключ главной таблицы
